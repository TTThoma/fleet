**Group by task**: press `g` and the sidebar shows one group per task — orchestrator first, every row naming its repo, branch and PR — with untagged sessions in the repo tree below. On a task header, `d` deletes the team's sessions, `z` snoozes the whole task, and `w` starts a new worker for it, asking which repo when the task spans several.
